# 🛒 Moderne Shops

> Neu mit **CityShops 2.4.0 Beta 1**

CityShops 2.4.0 erweitert das bestehende Shopsystem um moderne
Ladeneinrichtung.

Neben den klassischen ChestShops stehen jetzt **CityShops-Regale**,
**elektronische Preisschilder** und eine **Verkaufstheke** zur Verfügung.

> **Wichtig:** Die neuen Shops ersetzen die klassischen ChestShops nicht.
> Beide Systeme können gleichzeitig verwendet werden.

---

## 🏪 CityShops-Regal

Das CityShops-Regal ist ein neues platzierbares Shopsystem.

Ein Regal benötigt nur **eine Blockposition** und besitzt zwei voneinander
getrennte Bereiche:

- oberes Regal
- unteres Regal

Jeder Bereich besitzt ein eigenes Inventar mit **54 Slots**.

### Inventar öffnen

Klicke mit Rechtsklick auf den gewünschten Regalbereich:

**Obere Regalhälfte**
→ öffnet das obere Inventar

**Untere Regalhälfte**
→ öffnet das untere Inventar

Beide Inventare werden unabhängig voneinander gespeichert.

---

## 📦 Sichtbare Waren

Waren aus dem Regal werden direkt auf den Regalböden dargestellt.

Dadurch können Spieler bereits von außen erkennen, welche Produkte
in einem Regal angeboten werden.

Die sichtbaren Waren werden automatisch aktualisiert, wenn sich der
Inhalt des Regals ändert.

---

## 🖥️ Elektronisches Preisschild

Für moderne Regalshops gibt es ein eigenes elektronisches Preisschild.

Ein Regal kann maximal **zwei Displays** besitzen:

- ein Display für das obere Regal
- ein Display für das untere Regal

Die Displays werden direkt am jeweiligen Regalbereich montiert.

Ein zusätzliches normales Minecraft-Schild wird für diesen Shoptyp
nicht benötigt.

---

## 🛠️ Regalshop erstellen

Nimm ein **elektronisches Preisschild** in die Hand und klicke auf den
gewünschten Regalbereich.

Anschließend öffnet sich die Shop-Konfiguration.

Dort kannst du einstellen:

- **Verkauf**
- **Ankauf**
- **Menge**
- **Preis**

Nach der Einrichtung wird das elektronische Preisschild automatisch
am Regal montiert.

---

## 💰 Elektronisches Preisschild

Das Display zeigt die wichtigsten Informationen des Shops direkt an.

Dazu gehören:

- Artikel
- Shoptyp
- Preis
- Bestand

Bei einer Änderung des Warenbestands wird die Anzeige automatisch
aktualisiert.

---

## 🛒 Shop benutzen

Spieler können direkt auf das elektronische Preisschild klicken.

Bei einem Verkaufsshop wird der eingestellte Artikel gekauft.

Bei einem Ankaufsshop kann der entsprechende Artikel an den Shop
verkauft werden.

Die Transaktion verwendet weiterhin die normale CityShops-Logik.

Dazu gehören unter anderem:

- MineBank
- Firmenkonten
- Warenbestand
- Statistiken
- Mitarbeiterrechte

---

## 📦 Regal weiterhin öffnen

Ein montiertes Display verhindert nicht den Zugriff auf das Regal.

Klicke **links oder rechts neben dem Display**, um weiterhin das
entsprechende Regalinventar zu öffnen.

Klick direkt auf das Display:

→ Shop benutzen

Klick neben das Display:

→ Regalinventar öffnen

---

## ✂️ Elektronisches Preisschild entfernen

Berechtigte Besitzer und Mitarbeiter können ein montiertes
Preisschild wieder entfernen.

Dazu:

1. Schleichen
2. Schere in die Hand nehmen
3. Auf das elektronische Preisschild klicken

Das Display wird entfernt und zurückgegeben.

Die Waren im Regal bleiben dabei erhalten.

---

## ⛏️ Regal abbauen

Beim Abbau eines Regals werden die enthaltenen Waren nicht gelöscht.

Zurückgegeben werden:

- das CityShops-Regal
- Waren aus beiden Inventaren
- montierte elektronische Preisschilder

Dadurch können gefüllte Regale sicher entfernt werden.

---

## 🔄 Trichter-Unterstützung

CityShops-Regale können auch mit Trichtern verwendet werden.

**Trichter von oben**

→ verwendet das obere Inventar

**Trichter von unten oder von der Seite**

→ verwendet das untere Inventar

Damit können Regalshops auch in automatisierte Lagersysteme
eingebunden werden.

---

# 🧱 Verkaufstheke

CityShops 2.4.0 enthält außerdem eine neue **CityShops-Verkaufstheke**.

Die Verkaufstheke bietet eine weitere moderne Möglichkeit,
CityShops in Geschäften und Verkaufsräumen darzustellen.

Sie verwendet dieselbe grundlegende CityShops-Shoplogik wie die
anderen Shopvarianten.

---

# 🎨 CityShops-Kreativinventar

CityShops besitzt ab Version 2.4.0 einen eigenen Tab im
Minecraft-Kreativinventar.

Dort findest du unter anderem:

- CityShops-PC
- CityShops-Regal
- CityShops-Verkaufstheke
- elektronisches Preisschild

Dadurch müssen die neuen Blöcke und Items im Kreativmodus nicht
über Befehle gesucht werden.

# 📦 Klassische ChestShops bleiben erhalten

Das neue Regalsystem ersetzt die bisherigen ChestShops **nicht**.

Bestehende Shops mit Kiste und normalem Minecraft-Schild können
weiterhin verwendet werden und müssen nicht neu erstellt werden.

### Klassischer Shop

**Kiste + normales Minecraft-Schild**

### Moderner Shop

**CityShops-Regal + elektronisches Preisschild**

Beide Varianten können gleichzeitig auf demselben Server verwendet
werden.

Sie verwenden weiterhin die gemeinsame CityShops-Logik für:

- Ankauf und Verkauf
- Firmen
- MineBank
- Mitarbeiterrechte
- Statistiken

# ⚠️ Beta-Hinweis

**CityShops 2.4.0 Beta 1** ist eine Beta-Version.

Vor einem Update sollte eine Sicherung der Minecraft-Welt erstellt
werden.

Für Server wird empfohlen, die Beta zunächst auf einer Testwelt oder
einer Kopie der bestehenden Welt zu testen.

MineBank **1.0.2 oder neuer** wird weiterhin benötigt.
