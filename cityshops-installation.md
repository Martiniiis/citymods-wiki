# 🚀 CityShops – Installation

Auf dieser Seite erfährst du, wie du **CityShops** auf deinem Minecraft-Server installierst.

---

## 📦 Voraussetzungen

CityShops ist für folgende Minecraft-Version entwickelt:

- **Minecraft:** 1.20.1
- **Modloader:** Forge

Weitere benötigte Mods und die jeweiligen Mindestversionen findest du bei der entsprechenden CityShops-Version auf der Downloadseite.

---

## 📥 Installation

### 1. CityShops herunterladen

Lade die gewünschte Version von **CityShops** herunter.

### 2. Server stoppen

Stoppe deinen Minecraft-Server vollständig, bevor du CityShops installierst oder aktualisierst.

### 3. Mod installieren

Kopiere die heruntergeladene CityShops-Datei in den `mods`-Ordner deines Minecraft-Servers.

Beispiel:

`minecraft/mods/CityShops-VERSION.jar`

### 4. Abhängigkeiten installieren

Stelle sicher, dass alle für CityShops benötigten Abhängigkeiten ebenfalls im `mods`-Ordner vorhanden sind.

### 5. Server starten

Starte anschließend deinen Minecraft-Server.

Wenn CityShops und alle benötigten Abhängigkeiten korrekt installiert wurden, wird der Mod beim Serverstart geladen.

---

## 🔄 CityShops aktualisieren

Wenn du eine ältere CityShops-Version aktualisierst:

1. Stoppe den Server.
2. Entferne die alte CityShops-JAR aus dem `mods`-Ordner.
3. Kopiere die neue CityShops-JAR in den `mods`-Ordner.
4. Prüfe, ob sich benötigte Abhängigkeiten geändert haben.
5. Starte den Server wieder.

> **Hinweis:** Erstelle vor größeren Updates sicherheitshalber ein Backup deiner Welt und Serverdaten.

---

## ❓ Probleme bei der Installation?

Sollte der Server nach der Installation nicht starten, prüfe zuerst:

- ob die richtige Minecraft-Version verwendet wird,
- ob die richtige Forge-Version installiert ist,
- ob alle benötigten Abhängigkeiten vorhanden sind,
- und ob im Server-Log Fehlermeldungen zu CityShops angezeigt werden.
