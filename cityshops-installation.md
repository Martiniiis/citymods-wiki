# 🚀 CityShops – Installation

Auf dieser Seite erfährst du, wie du **[CityShops](https://www.curseforge.com/minecraft/mc-mods/cityshops)** auf deinem Minecraft-Server und Client installierst.

---

## 📦 Voraussetzungen

CityShops ist für folgende Minecraft-Version entwickelt:

- **Minecraft:** 1.20.1
- **Modloader:** Forge
- **[MineBank](https://www.curseforge.com/minecraft/mc-mods/minebank):** Erforderliche Abhängigkeit

> ⚠️ **Wichtig:** CityShops muss sowohl auf dem **Minecraft-Server** als auch auf den **Clients der Spieler** installiert sein.

---

## 🏦 MineBank

CityShops benötigt **[MineBank](https://www.curseforge.com/minecraft/mc-mods/minebank)** als Abhängigkeit.

Ohne MineBank kann CityShops nicht ordnungsgemäß geladen und verwendet werden.

Achte darauf, dass die für deine CityShops-Version benötigte MineBank-Version installiert ist.

> **Hinweis:** MineBank ist eine externe Abhängigkeit und kein Bestandteil von CityShops.

---

## 🖥️ Installation auf dem Server

### 1. Server stoppen

Stoppe deinen Minecraft-Server vollständig, bevor du CityShops installierst oder aktualisierst.

### 2. CityShops herunterladen

Lade die gewünschte Version von **[CityShops](https://www.curseforge.com/minecraft/mc-mods/cityshops)** herunter.

### 3. CityShops installieren

Kopiere die heruntergeladene CityShops-JAR in den `mods`-Ordner deines Minecraft-Servers.

Beispiel:

`minecraft/mods/CityShops-VERSION.jar`

### 4. MineBank installieren

Lade die benötigte Version von **[MineBank](https://www.curseforge.com/minecraft/mc-mods/minebank)** herunter und kopiere die JAR-Datei ebenfalls in den `mods`-Ordner des Servers.

Im `mods`-Ordner müssen anschließend mindestens folgende Mods vorhanden sein:

- CityShops
- MineBank

### 5. Server starten

Starte anschließend deinen Minecraft-Server.

Wenn CityShops und MineBank korrekt installiert wurden, sollte CityShops beim Serverstart geladen werden.

---

## 🎮 Installation auf dem Client

CityShops ist **kein reiner Server-Mod**.

Jeder Spieler, der auf einem Server mit CityShops spielen möchte, benötigt CityShops ebenfalls auf seinem Minecraft-Client.

### 1. Minecraft schließen

Beende Minecraft vollständig.

### 2. CityShops installieren

Kopiere die CityShops-JAR in den lokalen `mods`-Ordner deiner Minecraft-Installation.

### 3. MineBank installieren

Installiere auch die benötigte MineBank-Version im lokalen `mods`-Ordner.

Auf dem Client müssen somit ebenfalls mindestens folgende Mods vorhanden sein:

- CityShops
- MineBank

### 4. Minecraft starten

Starte Minecraft anschließend mit dem passenden **Forge-Profil für Minecraft 1.20.1**.

---

## ⚠️ Server und Client

Damit Spieler einem CityShops-Server beitreten können, müssen die benötigten Mods auf beiden Seiten vorhanden sein.

| Server | Client |
| --- | --- |
| ✅ CityShops | ✅ CityShops |
| ✅ MineBank | ✅ MineBank |
| ✅ Forge | ✅ Forge |

Achte außerdem darauf, dass Server und Client die jeweils kompatiblen Mod-Versionen verwenden.

---

## 🔄 CityShops aktualisieren

Wenn du CityShops auf eine neuere Version aktualisieren möchtest:

1. Stoppe den Minecraft-Server.
2. Erstelle sicherheitshalber ein Backup deiner Welt und Serverdaten.
3. Entferne die alte CityShops-JAR aus dem `mods`-Ordner.
4. Kopiere die neue CityShops-JAR in den `mods`-Ordner.
5. Prüfe, ob für die neue CityShops-Version eine andere MineBank-Version benötigt wird.
6. Aktualisiere CityShops gegebenenfalls auch auf den Clients.
7. Starte den Server und die Clients anschließend neu.

> ⚠️ **Empfehlung:** Erstelle vor größeren CityShops-Updates immer ein Backup deiner Welt und Serverdaten.

---

## ❓ Probleme bei der Installation?

Sollte Minecraft oder der Server nach der Installation nicht starten, überprüfe zuerst:

- Wird **Minecraft 1.20.1** verwendet?
- Wird die passende **Forge-Version** verwendet?
- Ist **CityShops** installiert?
- Ist **MineBank** installiert?
- Sind CityShops und MineBank auf **Server und Client** vorhanden?
- Sind die installierten Versionen miteinander kompatibel?
- Gibt es im Server-Log oder Client-Log eine Fehlermeldung zu CityShops oder MineBank?
